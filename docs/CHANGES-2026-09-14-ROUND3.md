Everything else (description, pay, hours, requirements, benefits, dates, apply details, audiences…) stays editable by the owner at any time.

Every template you touch must render for: draft, pending_payment, active, expired, cancelled, inactive, Job Bank reference rows, jobs with 0/1/3 locations, missing operating name, missing hours/salary. Test all of them.
5. **Rename "Apply link" → "Other platform link"** everywhere (form label, hint "If you also accept applications on another job board or your own site", preview, public page CTA "Apply on other platform"). Field name `apply_url` unchanged.
6. **Posting ID `X1X1X1`** — `jobs.public_id` (letter-digit ×3, e.g. `K4T7M2`; `lib/jobs.js ensurePublicId(jobId)` allocates; `activateJob` allocates on first activation; the fixes agent also allocates on create so drafts have one).
